# Contributing

1. Open an issue describing the behavior and safety impact.
2. Use fictional candidate/job fixtures only.
3. Keep deterministic logic testable without paid APIs.
4. Never let browser tests reach a real employer submission control.
5. Run backend tests, Python compilation, frontend lint, and the production build.

Do not commit `.env` files, local profiles, resumes, databases, browser state, screenshots, application payloads, or generated artifacts. Security reports should follow [SECURITY.md](SECURITY.md).

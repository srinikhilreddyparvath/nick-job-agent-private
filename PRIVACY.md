# Privacy

Candidate profiles can contain identity, contact, employment, compensation, and immigration information. Real data belongs only in ignored local configuration or appropriately secured production storage.

The public repository contains fictional examples. Before sharing a fork, inspect git history and the working tree for resumes, databases, artifacts, logs, screenshots, browser recordings, job-application answers, and secrets. Generated resumes and browser diagnostics must never be exposed through unauthenticated public artifact URLs.

The project does not scrape authenticated LinkedIn or infer sensitive demographic facts. Unknown information remains unknown unless the user explicitly approves a policy.
